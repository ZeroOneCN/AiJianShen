# 爱健身 1.9.5 方案

> 范围：训练中页面的交互重构 + 图标语义修补。版本号不变，仍为 **1.9.5**。
> 分支：`test/upscaled-webp`。日期：2026-11-19。

## 一、这一版要解决的三件事

| # | 问题 | 现状 | 目标 |
|---|------|------|------|
| 1 | 「⋯」是底部弹窗 | 点顶部按钮，卡片从屏幕底部升起，手指要跨半屏 | 贴着按钮向右下展开的真下拉 |
| 2 | 底部按钮压在动作图上 | 收藏/换一个浮在演示图右下角，休息时加时/跳过浮层又与之重叠 | 演示图与操作条分区，任何状态下都不遮挡 |
| 3 | 图标语义不准 | 收藏是五角星、换动作是环形箭头（与"同步/恢复"同图）、Wi-Fi 只有两道弧 | 收藏=书签、换动作=双向交换、Wi-Fi=三弧收口 |

## 二、交互方案

### 2.1 顶部「⋯」改真下拉

- 用 `PopupWindow` 锚定 `btn_more`，`showAsDropDown(anchor, 0, 6dp, Gravity.END)`，**右边缘与按钮对齐**，不会溢出屏幕。
- 白卡 + 16dp 圆角 + 1px 淡描边 + 10dp 投影。页面本身是白底，没有描边和投影时菜单会"消失"在页面里。
- 三条：动作要领与帮助 / 背景音乐（播放中会带后缀）/ 训练设置。**去掉箭头**——下拉不需要再暗示"进入下一层"。
- 收起方式：点条目、点空白、返回键。点条目时先 `dismiss()` 再执行动作，避免菜单压在下一个页面上。

### 2.2 演示区与操作条分区

```
┌──────────────────────────┐
│ 返回      动作名      ⋯   │  顶栏：三段等宽
├──────────────────────────┤
│                          │
│        动作演示图         │  图区：底部留 62dp
│                          │
├──────────────────────────┤
│      [书签]  [换一个]     │  操作条：44dp 固定高
└──────────────────────────┘
   进行中 / 进度环 / 动作名 / 要领
   上一动作   暂停   下一动作
```

- 图区 `PhotoView` 加 `marginBottom=62dp`，操作条落在这 62dp 里，**图上不再有任何浮层**。
- 操作条是**一条固定的带**，常态放收藏/换一个，休息时整条换成「+15 秒 / 跳过休息」。容器高度恒定 44dp —— 换的是内容不是高度，所以页面不会抖。
- 按钮底色从玻璃白改为 `CARD_SOFT`：白色按钮压在白色页面上会看不见，原来的玻璃白只有在图片上才成立。

### 2.3 状态说明

| 状态 | 操作条内容 | 说明 |
|------|-----------|------|
| 练习中 | 书签（已收藏为橙色）+ 换一个 | 两个都是低频但需要随手可及的动作 |
| 休息中 | +15 秒（浅底）+ 跳过休息（实心绿） | 跳过是主操作，加时是次操作，用底色区分权重 |

## 三、图标方案

| 图标 | 原来 | 现在 | 理由 |
|------|------|------|------|
| 收藏 | `ic_star` 五角星 | `ic_bookmark` 书签 | 星标在中文语境里更多是"评分/加星"，书签才是"收藏起来以后看"；训练页、动作库统一 |
| 换一个 | `ic_refresh` 环形箭头 | `ic_swap` 双向箭头 | 环形箭头与"同步/从备份恢复"同图，用户会以为在刷新数据；双向箭头才是"换一个动作" |
| Wi-Fi | 两道弧 + 圆点，弧线偏细偏断 | 三道弧 + 收口圆点 | 三弧是通行画法，弧口朝上、信号感更强；仍按包围盒归一化到 88% 视口 |

- 新图标沿用同一套规格：24 视口、`strokeWidth` 视觉恒为 2 单位、包围盒占视口 88%。
- `ic_star` 与 `ic_refresh` 保留：前者仍用于「成就/关于」，后者仍用于「从备份恢复 / 振动 / 同步」。

## 五、后续（1.9.6 候选）

1. 操作条右侧可再加「本轮跳过」与「休息 +30 秒」的长按菜单，减少进设置改参数的次数。
2. 动作要领支持「展开全文」，长要领默认两行 + 展开，避免 sheet 过高挤掉进度环。
3. 收藏与「我的训练」打通：练中收藏的动作可直接生成模板。
4. 下拉菜单补一条「退出本次训练」，替代目前必须点返回才会出现的确认框。
